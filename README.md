# FirGrok2

一个用 Vite 搭建的简单 React 项目。

线上地址：https://ssttmkkw-hue.github.io/FirGrok2/

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端里显示的地址（默认 http://localhost:5173）。

## 构建

```bash
npm run build
npm run preview
```

## 自动部署

推送到 `main` 后，GitHub Actions 会构建并发布到 GitHub Pages。
仓库 Settings → Pages → Source 需选 **GitHub Actions**。
